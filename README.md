# 10pix

https://plairpro.github.io/10pix/

Общее полотно 1920×1080, сетка 192×108. Один браузер может сделать 10 закрашиваний, включая перекрашивание чужих клеток. Палитра всегда под полотном. Стрелка назад отменяет последнее собственное действие и возвращает один пиксель; более поздние действия других участников сохраняются.

Вход не требуется. Лимит привязан к cookie браузера; очистка cookie или другой браузер позволяет начать заново. Сервер проверяет лимит атомарно. Старые пиксели сохранены и учитываются в лимите.

GitHub Pages открывает рабочее приложение на https://million-pixels-timur.timurfazullin.chatgpt.site. Общая база Cloudflare D1 и сервер работают на Sites, поскольку GitHub Pages обслуживает только статические файлы. Архив 10pix-source.zip содержит полный исходный код без данных пользователей и секретов.

Проверка: npm ci, npm run db:generate, node tests/canvas.mjs, npx tsc --noEmit, npm run build.
